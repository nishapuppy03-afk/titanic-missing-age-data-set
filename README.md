In this project, I focused on handling missing values in the Age column of the Titanic dataset. I identified missing data using isnull() and isnull().sum(), and then applied dropna() to remove incomplete rows where necessary. To retain as much data as possible, I also filled missing values using the column’s mean and median with fillna(). Additionally, I performed encoding to prepare the dataset for analysis or machine learning tasks. By cleaning and transforming the data, this project ensures a reliable dataset for exploring passenger demographics, survival patterns, and building predictive models. The approach demonstrates practical techniques for handling missing data in real-world datasets.
